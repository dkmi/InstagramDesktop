# InstagramDesktop

Малко macOS приложение, което отваря Instagram в отделен прозорец чрез WebKit.

1. Отворете `InstagramDesktop.xcodeproj` с Xcode.
2. Изберете схемата `InstagramDesktop` и `My Mac`.
3. Натиснете Run (`Command-R`).
4. Влезте в Instagram. WebKit пази cookies и сесията между стартиранията.

За самостоятелен `.app` използвайте **Product > Archive** или **Product > Show Build Folder in Finder** след build.
